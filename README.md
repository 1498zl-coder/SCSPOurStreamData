# SCSPOurStreamData

棱镜拾光 · Prism Memories 的OurSTREAM 节目资源数据仓库。客户端 2.18.0，资源 20006100。

当前完整版本：[ourstream-61-v2](https://github.com/1498zl-coder/SCSPOurStreamData/releases/tag/ourstream-61-v2)，61 个独立内容包，合计 5.53 GB。

推荐通过支持本版本的启动器下载。首次安装可整包取得，少量补缺或修复可按位置索引读取需要的文件；每个启用文件均按原始 SHA256 校验。ZIP 是独立容器，无需全部下载后拼接。

## 后续更新

游戏新版本提供完整新索引，历史中相同内容继续引用固定旧包，只有未登记的新内容进入新增包。OurSTREAM 新节目独立追加；节目修订发布新的节目包。各版本索引直接描述完整目标，不要求按顺序安装历次补丁。

Git保存说明和小型版本入口，资源正文、完整catalog与压缩成员索引存放在Releases。游戏程序由独立项目提供。

GitHub自动生成的Source code ZIP/TAR只包含仓库文件，不包含资源正文。这里不存放玩家资料、认证信息、存档、照片或日志。
